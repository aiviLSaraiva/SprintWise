# Código-fonte

Nesta pasta ficam os códigos Java do SprintWise, separados pelo papel que desempenham no sistema.

- `classes`: estruturas que representam os dados.
- `servicos`: regras e operações.
- `menus`: interação pelo terminal.
- `persistencia`: leitura e gravação dos dados.

Antes de criar um arquivo, confira a explicação da pasta correspondente.
